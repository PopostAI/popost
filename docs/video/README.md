# The video engine (`popost video`)

The engine behind popost's video re-creation and template-based video generation: a project file becomes a page that
shows any frame and an MP4; any video file becomes a measurement and a score. It is part of the popost Skill
(`skills/popost/src/video/`, commands `popost video …`), developed on the branch `feat/video` and not in a published
release yet.
