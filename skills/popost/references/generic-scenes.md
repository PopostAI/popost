# 通用内容结构（generic-scenes）

> 性质：与杂志美学、与平台都无关的五个通用内容结构：**带货 / 比较 / 步骤 / 清单 /
> 观点**。结构 = 信息如何排列；平台只决定画幅/语言/安全区（见 `platform-adaptation.md`），
> 不改写结构的固定关系。视觉配色、字感、插画风格是可变轴，不在本文件锁定。
>
> 真实性红线（五结构通用）：价格、销量、评分、评价、折扣稀缺、效果/疗效承诺不得
> 虚构；无来源事实不写；测试/示例内容明确标注虚构或设计举例；示意素材标「示意」；
> 不承诺爆款、涨粉、成交等效果。

## 1. 带货 commerce-sell（情境 → 动作 → 价值回指 → 边界）

**适用**：把「用户情境/问题 → 商品身份 → 具体使用动作 → 价值回指动作或可核实属性
→ 适用边界」组织成带货或非交易性商品说明。
**选用信号**：怎么用、上手、使用场景、搭配携带、价值主张。
**不适用**：横向多款比较（→ §2）、通用无商品流程（→ §3）、概念解释。

**固定关系**
- 顺序固定：先情境/问题，再商品身份与动作；每条价值必须回指一个动作或可核实属性，
  不允许悬空赞美。
- 一页一个主视觉焦点；身份图与动作示意分开，标签紧邻被指对象。
- 层级：主标题 → 视觉/动作 → 支撑说明 → 边界/下一步；CTA 可选，不压过限制条件。
- 同一商品跨页身份、名称、描述一致；未确认商品只用标注清楚的概念示意。

**可变轴**：焦点（产品近景/使用情境/动作序列三选一）；密度（一个动作深讲或 2–4 个
场景并列，并列须各带新信息）；语气（中文解释 / 英文简短指令）；图文比（有授权图
突出身份，无图用原创示意）。

**单页闭环**：情境标题 + 商品身份/明确示意 + 1–3 个动作或属性 + 适用边界。
**多页分工**：封面提使用问题 → 动作页给动作与理由 → 细节页讲适配/维护/注意 →
收尾页归纳边界与下一步；每页新增信息，不重复封面句。

**禁忌**：功效/疗效承诺；伪折扣、倒计时稀缺；把示意当真实测评；相关性写成因果。

## 2. 比较 comparison（同口径并列 → 条件指向）

**适用**：2–3 个同类对象在同一口径下并列，按使用条件给出「什么情况下更匹配谁」。
**选用信号**：对比、区别、哪个更适合、vs、参数对照。
**不适用**：单品种草（→ §1）、从需求筛选未知品类（选购建议另立）、按时间操作（→ §3）。

**固定关系**
- 先约定对比维度，再并列对象；同一维度行内各对象用同一口径，禁止一行比容量、
  下一行比感受。
- 对象列等宽对等，视觉权重不因营销强弱倾斜；维度标签固定在对照体系一侧。
- 结论是「使用条件 → 更匹配谁」，不打伪星级、伪分数、伪排名，不写「绝对更好」。
- 参数缺失标「以规格为准 / 待补证据」；价格销量评价不虚构。

**可变轴**：对象数（2 双卡 / 3 矩阵）；维度数（3–5 为宜，超 5 拆页）；版面
（双卡左右 / 三列矩阵 / 上下堆叠）；结论位置（单页条件条 / 独立条件页）。

**单页闭环**：对象身份 + 约定维度 + 同口径对照 + 一条条件指向 + 证据边界。
**多页分工**：对照页只摆清楚；条件页讲「什么条件偏向谁」；证据页（可选）列待补
参数与核实渠道；不重复整表凑页。

**禁忌**：伪造参数/价格/评分；踩一捧一；不对等排版；无条件绝对推荐。

## 3. 步骤 step-guide（前置清单 → 有序步骤 → 完成检查）

**适用**：有先后顺序的一套操作，讲清「先做什么、再做什么、怎么算做完」，不绑定
单一商品推销。
**选用信号**：怎么做、教程、分步、更换、安装、清洁、组装。
**不适用**：单商品使用价值（→ §1）、横向比较（→ §2）、概念机制。

**固定关系**
- 编号即先后，不可调换跳步；上一步结果是下一步入口。
- 每步三要素：动作 → 预期结果 → 与下一步衔接，不只有动作口号。
- 前置材料/工具清单排在步骤前；安全/断电类提示在相关步骤旁可见，不藏末尾小字。
- 必须出现完成态检查点（怎么算这步完成、整套做完的标志）。
- 通用流程不伪装品牌官方教程；品牌专属操作以官方说明为准。

**可变轴**：步骤数（3–5 单页，超 5 按阶段拆页）；走向（纵向链 / 横向时间轴 /
左右交替）；详略（每步深讲 / 并列简步，简步也要有结果）；视觉（工序笔记 /
勾选清单）。

**单页闭环**：前置清单 + 3–5 有序步骤 + 完成检查。
**多页分工**：准备页列材料；操作页按阶段分段、页尾衔接；验收页集中完成检查与
常见失误；编号连续，不拆一步凑两页。

**禁忌**：跳步倒序；把可选写成必须；弱化/后置安全警示；虚构效果数值；省略完成检查。

## 4. 清单 curated-list（标准先于条目 → 平行条目三段 → 挑选方式）

**适用**：按一套事先说清的标准，筛出若干同层级平行条目，给可挑选候选池。
**选用信号**：合集、盘点、入门先看、候选清单、按标准挑。
**不适用**：有先后顺序（→ §3）、单概念机制、立场论证（→ §5）、逐项参数对比（→ §2）。

**固定关系**
- 筛选标准先于条目：先知道「凭什么入选」再看条目。
- 条目同层级平行：编号连续、结构一致，每条可单独抽走而不破坏其余。
- 每条三段：名称/方向 → 为什么入选（对应标准）→ 使用注意或依据。
- 主观偏好与客观依据分层标注；结尾给使用方式（怎么挑、从哪条开始），不宣称
  「最好/第一/必买」。

**可变轴**：条目数（3 轻 / 4 标准 / 5 上限，超出拆页）；形态（竖向编号 / 并列卡片
网格）；标准（一条总标准统领 / 2–3 条分标准逐条对应）；语气（中性导航 / 轻推荐，
不升级为断言）。

**单页闭环**：标准说明 + 3–5 条完整条目 + 一句挑选提示。
**多页分工**：首页立标准并给前半条目；次页给剩余条目 + 挑选小结；编号连续，
不在一条中间劈开，末页不补新标准。

**禁忌**：编造销量/评分/名次/品牌/出处；主观偏好写成客观排名；条目间换标准；
「最佳/第一/闭眼入」绝对化；AI 图冒充真实封面门店。

## 5. 观点 viewpoint（主张 → 证据块 → 反方/边界 → 限定结论）

**适用**：亮一个有立场的主张，分块摆支持理由，再呈现反方/边界，收束到「在什么
条件下成立」。适合评论、经验主张、利弊权衡。
**选用信号**：我认为、主张、值得讨论、支持/反对、利弊、在什么前提下成立。
**不适用**：概念是什么（概念解释另立）、时间推进（时间线另立）、并列挑选（→ §4）；
医疗/法律/政策不给保证性断言。

**固定关系**
- 观点句独立成块且最先出现，一句话说清立场。
- 支持证据分块并列，每块回指观点句，不堆砌无关事实。
- 反方/边界块不可省略：至少一条反对理由或前提缺失的情况。
- 证据强弱分层：真实个人观察（需用户素材）/ 一般经验推测 / 可核实来源；无素材时
  标「设计举例·示例性理由」，不冒充真实观察或研究。
- 结论限定适用条件，不推广为绝对真理；主张块层级最高，反方块可读同级。

**可变轴**：证据块数（2 精简 / 3 完整）；正反呈现（先正后反递进 / 左右对照）；
立场强度（探讨「可以这样看」/ 明确「我倾向认为」，均不用绝对化词）。

**单页闭环**：观点句 + 2–3 证据块 + 一条反方/边界 + 限定结论。
**多页分工**：首页亮观点 + 支持证据；次页反方条件 + 限定结论；观点句不重复抄写，
末页必须落到适用条件。

**禁忌**：推测写成定论；设计举例伪装真实观察/探店/调查；伪造研究/专家/统计；
隐藏反方或写成稻草人；「所有/必然/永远/百分百」；证据与观点脱钩。

## 6. 五结构速查

| 结构 | 一句话 | 核心闭环 | 不要用于 |
|---|---|---|---|
| 带货 commerce-sell | 情境→动作→价值回指→边界 | 情境+身份+1–3动作+边界 | 横评、疗效承诺 |
| 比较 comparison | 同口径并列→条件指向 | 身份+维度+对照+条件指向 | 单方推销、伪排名 |
| 步骤 step-guide | 有序教会一件事 | 前置清单+步骤+完成检查 | 并列合集、发散观点 |
| 清单 curated-list | 标准下平行收录 | 标准+条目三段+挑选方式 | 单产品深讲、线性教程 |
| 观点 viewpoint | 主张证据制衡收束 | 观点+证据+反方+限定结论 | 无证据情绪表态 |
