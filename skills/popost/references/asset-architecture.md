# 素材架构

五种常见结构，没有默认项：连续场景、独立图槽、原生图形排版、透明主体叠放、分层拼贴。选择依据是视觉关系与后续编辑需要。

共享光线、透视、反射或物理接触的元素宜放在同一连续场景中；需要独立位置、重复、替换、裁切或遮挡关系的元素独立承载。简单纸片、线条、框、可控几何用 HTML/CSS；摄影、材质与复杂插画用真实素材或模型。

有多个正式素材时写 asset-plan.json，记录 id、适用页面、用途、来源、形态、制作意图区域、层序、提示词标识、参考角色、风格锚点和依赖。该文件是素材制作计划，不是运行时布局 DSL；页面 HTML 始终决定最终坐标。

需要保留真实人物/商品/品牌等身份时明确 identity 约束；普通视觉原创可以没有身份参考。style、layout、action 和 identity 的含义分开，不能把风格图的商品默认迁入目标作品。材料路由的 productIdentity.required 或 slot.requiresIdentity 只在身份敏感任务启用。

逐个检查素材（几张一起用 `sheet --files …` 拼成一张看），再看组装：接缝、尺度、光线、重复、错配、透明边缘和遮挡。图像必须说明对应页的信息；几幅不同含义不应误用同一张图。内部一张多页参考联系表只指导风格，不裁开当作正式素材。
