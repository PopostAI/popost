# 内容与视觉系统

在参考确定后做一次整合判断，写入 design.md。先决定观看顺序：什么抓住眼睛、什么表达主张、什么提供细节。尺寸、字重、色彩和留白共同形成明显层级，避免所有模块同等重要。

整组共享设计规则，各页可变化。字体按 display/body/caption 等角色选择，字形覆盖实际语言，字阶有足够差异；参考或品牌规定单一字体时沿用，不强凑字体数量。色彩按背景、正文、强调与语义分配，不按固定数量填色。网格和留白承担结构，装饰不替代有意义的照片、插画或图解。

图片区先实际检查再落文字：提示词要求的干净区域不保证真实尺寸；测量返回图的低细节区域、裁切和主体范围。需要字图对比时先选适当区域、局部渐变/衬底或合乎设计的面板，避免每处都放黑色文字框。

每页 HTML 是最终几何权威。固定画布用像素定义排版尺寸，palette/font roles 用 :root 变量；语义图层可独立移动，复杂场景可为一层位图。嵌套文字用 data-slot，不嵌套可拖动 layer-id。结构 wrapper 可保留；不将其误认为遗漏图层。

使用 border-box，保持变换和层序；字体、图片加载后再测量。模板或旧文件存在流式布局时谨慎固化，避免边测量边改变布局。画布几何、编辑器几何和导出结果必须一致。
