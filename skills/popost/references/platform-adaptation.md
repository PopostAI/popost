# 五平台设计起点

平台影响画幅、密度、图文关系、留白、文案和行动引导。以下是设计预设，不是官方发布限制；正式发布规则按当期平台要求核验。用户指定规格优先。语言和市场由受众决定，不随平台名自动锁定。

| 平台 | 设计起点 | 传播与阅读重点 |
|---|---|---|
| TikTok | 3:4 或 9:16，视实际发布用途 | 首屏识别、图像焦点、连续阅读；关键字避开界面覆盖 |
| 抖音 | 3:4 或 9:16 | 简洁明确的主张、清晰步骤与视觉承接 |
| 小红书 | 3:4 | 封面承诺、内页可收藏信息、具体且可信的表达 |
| Instagram | 4:5 或 1:1 | 全组审美一致、可分享的信息与图片节奏 |
| X | 16:9 或 1:1，按内容调整 | 独立可理解的主张、图中信息与帖文配合 |

钩子机制按受众、主题和真实价值选择；CTA 按发布目标决定，所有平台均可不设 CTA。预留合理边距，避免关键内容贴边；不把来源不明的安全区百分比当硬限制。不把社媒图文一律写成电商带货，也不把同一排版只缩放后称跨平台适配。
