# 原创

First establish the audience and content plan. When useful and authorized, use one optional, separately priced composition reference to explore the series. Skip generation for a local-material/no-generation route and record the reason; see [onboarding.md](onboarding.md). 创意增强锁定事实、对象和用户指定内容，强化取景、尺度对比、层级、字体张力、材质、光线与空间节奏。不要给模型凭空加新品牌、事件、商品或功效。

When an internal reference is selected, the workflow is: 建页 → 计划 → `series prompt` → `image prepare` → 所选通道生成一张 → `image complete` → 读图写 design.md → 正式素材 → 活字 HTML → 看图修正。

多页联系表一次输出所有页面；不额外生成封面方向、内页方向或逐页概念。图片里允许展示计划文字以确定层级，但不会用于最终排字。正式素材计划在读完参考后确定；一次参考预算不意味着正式摄影/插画素材也免费。

计划先解决内容，读参考后整合最终文案与视觉判断。参考生成的文字有错就以计划为准，事实绝不从模型补全。需要视觉创作时不默认排几个圆角卡片；纯排版也应有鲜明字阶、图形秩序和留白，不能靠泛用渐变填空。

单图与多图使用相同设计原则。多页全组共享视觉锚点；无需每页重复一个主体或同一段标题。连续摄影与多人动作先确保物理关系，再决定拆层。

关闭参考要记录原因：用户明确关闭、局部编辑不影响构图、或能力缺失但现有素材/原生排版可充分满足需求。关键生图能力缺失则说明缺口。
