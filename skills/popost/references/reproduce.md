# 本地参考复刻

本地图片先当一张总览来看：宿主已把它们合成一张编号总览图的就用它，否则用 `sheet --files <参考各页和商品图> --out …` 拼一张。页序从文件名和 `reference` 返回的清单核对，像素尺寸和透明通道用 `image info --file …` 一次读出（不要用 identify、python 或 node -e 去探测），不靠逐张打开；只有要核对细节（小字、商品细节）时才单独打开某一页，打开的每张图都会留在对话里。据此判断图片是目标、内容素材、身份图还是松散风格参考，再用 `reference --file ... --role layout|content|identity|style` 真实导入。看不清的文字和数字记录未知，不猜写。

## 保留与替换范围

忠实重建保留可见文字、主视觉尺度、位置关系、裁切、字体特征、色彩位置、装饰和页序；用户指定的替换单独列明。同款改编保留设计语言、页面机制与信息关系，按要求换内容或对象。只有氛围参考时进入原创。

观察可见事实，推断阅读逻辑，两者分开写。记录精确文案、主视觉与次视觉、字阶与行数、对齐、留白、层序、形状与质感；不只用“高级、杂志风”代替观察。

## 真实重建

文字和标签为活字 HTML，独立照片、主体和结构按语义分层。照片中已有包装印字作为照片内容保留。连续场景依赖共同光线/透视/手部接触时保持连贯；目标商品身份使用真实用户素材。普通插画和非商品主题不要求商品身份图。

原图可用的非文字图片区域按用户素材使用；内部生成的概念参考像素不交付。原帖文字遮住背景且没有干净素材时，选真实图像编辑能力重建，避免盖一块色板假装还原。无法恢复的纹理或字体明确记差异。

完成后与参考逐页并排看主视觉、版式、照片类型（场景照还是商品图）、字形风格、信息密度、阅读顺序和细节；多图再看整组。忠实复刻的参考无字时不擅加标题/CTA；改编的文案以用户新要求为准。场景与参考的职责先按用户说明分配，只有实质冲突才询问。

`strict` 是旧工程中的复刻模式名，不自动启用所有商品类限制。正常生产使用 build/逐页 review/series review；旧的商品动作探针可在确有该类任务时辅助检查，不构成每篇图文都要过的另一套流程。

用户的商品图只提供商品本身。它若是设计过的电商图（带标题、卖点徽章、参数图标），只取商品，不照搬它的版式和文案；每一页的版式、钩子位置和照片类型都跟随对应的参考页。

参考页是真人或场景照片（穿戴或使用场景、房间、户外）时，用生图做一张同类场景里的用户商品，按参考页写明场景（例如夜晚厨房的岛台），不换成别的场景；只有参考页本身是纯商品图或图形设计时，才直接用商品图。计划里写清哪一页用哪种。
