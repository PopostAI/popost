# 观点 · 主张证据与限定结论（viewpoint）

## 适用
亮一个有立场的主张，分块摆支持理由，再呈现反方/边界，收束到「在什么条件下成立」。
选用信号：我认为、主张、值得讨论、支持/反对、利弊、在什么前提下成立。不用于概念
是什么、时间推进、并列挑选；医疗/法律/政策不给保证性断言。

## 固定关系（不可破坏）
1. 观点句独立成块且最先出现，一句话说清立场。
2. 支持证据分块并列，每块回指观点句，不堆砌无关事实。
3. 反方/边界块不可省略：至少一条反对理由或前提缺失的情况。
4. 证据强弱分层：真实个人观察（需用户素材）/ 一般经验推测 / 可核实来源；无素材标
   「设计举例·示例性理由」，不冒充真实观察或研究。
5. 结论限定适用条件，不推广为绝对真理；主张块层级最高，反方块可读同级。

## 单页闭环
观点句 + 2–3 证据块 + 一条反方/边界 + 限定结论。

## 多页分工
- 首页：亮观点 + 支持证据块。
- 次页：反方条件 + 限定结论；观点句不重复抄写，末页必须落到适用条件。

## 填写作业单
- [ ] 观点句：一句话立场（≤2 行）。
- [ ] 证据块：2–3 块，每块「小标题+1–2 句理由」，回指观点。
- [ ] 反方：至少一条反对理由/边界，可读同级。
- [ ] 来源层：真实观察（用户素材）/ 经验推测 / 可核实来源；无素材标设计举例。
- [ ] 限定结论：在……情况下更成立，无绝对化词。

## 素材与红线
- 不引用虚构研究、专家、统计、调查比例；没有来源不写精确数据。
- 设计举例不得伪装真实个人观察、探店、调查结论；语气用「可能/示例性推测」。
- 医疗/法律/政策主张降为一般讨论，提示咨询专业人士，不给保证。

## 容量与重排
- 观点句 ≤2 行；证据块每块短；单页证据块 ≤3，超出拆页并带反方过去。
- 反方块不缩成一行小字；长标题拆主句+限定副题。
- 窄幅先观点后纵向证据；宽幅可正反左右对照，两侧条目层级对齐。

## 逐项验收
- [ ] 观点句独立、最先出现，一句话可复述；每块证据回指观点。
- [ ] 反方/边界在场且可读；证据强弱分层，无素材块标设计举例。
- [ ] 结论限定适用条件，无绝对化措辞；无虚构研究/专家/统计。
- [ ] 多页首页主张+证据，次页反方+结论，无重复、无拆块。
- [ ] 长标题/长块真实试排，无溢出/裁切/无限缩字。
