# 清单 · 标准下的平行收录（curated-list）

## 适用
按一套事先说清的标准，筛出若干同层级平行条目，给可挑选候选池。选用信号：合集、
盘点、入门先看、候选清单、按标准挑。不用于有先后顺序、单概念机制、立场论证、
逐项参数对比。

## 固定关系（不可破坏）
1. 筛选标准先于条目：先知道「凭什么入选」再看条目。
2. 条目同层级平行：编号连续、结构一致，每条可单独抽走而不破坏其余。
3. 每条三段：名称/方向 → 为什么入选（对应标准）→ 使用注意或依据。
4. 主观偏好与客观依据分层标注；结尾给使用方式（怎么挑、从哪条开始），不宣称
   「最好/第一/必买」。

## 单页闭环
标准说明 + 3–5 条完整条目 + 一句挑选提示。

## 多页分工
- 首页：立标准 + 前半条目（每条三段完整）。
- 次页：剩余条目 + 横向挑选小结；编号连续，不在一条中间劈开，末页不补新标准。

## 填写作业单
- [ ] 标准：一条总标准，或 2–3 条分标准逐条对应。
- [ ] 条目：3–5 条同层级；每条三段齐全（名称/入选理由/注意或依据）。
- [ ] 分层：主观偏好与客观依据分开标。
- [ ] 小结：怎么挑、从哪条开始；无绝对化断言。

## 素材与红线
- 真实条目（店铺/产品/书目/地点）需用户提供或检索确认来源授权；无授权只写抽象
  方向/类别，不写具体名称品牌，不用 AI 图冒充封面/招牌。
- 不编造销量、评分、排名、年份、获奖；依据块无核实则改写为经验性注意点。

## 容量与重排
- 单页条目上限 5；每条理由 2 短句内；长名称允许换行，编号与名称不分离。
- 缺条目减项保持完整，不注水凑数；缺素材改纯文字方向卡。
- 窄幅竖向列表，宽幅 2 列网格；每格三段齐全，注意点不挤成角标。

## 逐项验收
- [ ] 标准先出现，每条都能对应标准；条目同层级平行、编号连续、结构一致。
- [ ] 每条三段齐全；无虚构销量/评分/名次/品牌/出处。
- [ ] 结尾给挑选方式，无绝对化断言；多页编号连续、无拆条、无重复。
- [ ] 长标题/长名称真实试排，无溢出/裁切/无限缩字。
