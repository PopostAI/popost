# 比较 · 同口径并列与条件指向（comparison）

## 适用
把 2–3 个同类对象在同一口径下并列，按使用条件给出「什么情况下更匹配谁」。
选用信号：对比、区别、哪个更适合、vs、参数对照。不用于单品种草、从需求筛选未知
品类、按时间操作。

## 固定关系（不可破坏）
1. 先约定对比维度，再并列对象；同一维度行内各对象用同一口径，禁止一行比容量、
   下一行比感受。
2. 对象列等宽对等，视觉权重不因营销强弱倾斜；维度标签固定在对照体系一侧。
3. 结论是「使用条件 → 更匹配谁」，不打伪星级、伪分数、伪排名，不写「绝对更好」。
4. 参数缺失标「以规格为准 / 待补证据」；价格、销量、评价不虚构。

## 单页闭环
对象身份 + 约定维度 + 同口径对照 + 一条条件指向 + 证据边界。

## 多页分工
- 对照页：只把同口径摆清楚，不给结论。
- 条件页：什么条件下偏向谁；不重复整表。
- 证据页（可选）：列待补参数与核实渠道。跨页对象名、维度名、口径完全沿用。

## 填写作业单
- [ ] 对象：2 个双卡 / 3 个矩阵；同类、可比。
- [ ] 维度：3–5 个，同一维度各对象口径一致（都讲材质，或都讲适用场景）。
- [ ] 参数：只写可核实值；缺则「以规格为准」。
- [ ] 条件指向：列出 2–3 种使用条件，各自偏向谁。
- [ ] 证据边界：哪些参数待补、去哪核实。

## 素材与红线
- 不伪造参数、价格、销量、评分、排名；不造满分星级。
- 不踩一捧一，不把适用条件写成绝对优劣；不混淆相关与因果。
- 对象身份图需授权或确认同款；无图用类型轮廓示意并标「示意」。

## 容量与重排
- 对象 >3 或维度 >5 拆页，每段保持完整维度组；维度名长在标签格内换行，不缩字。
- 窄幅：对象由左右并列改上下堆叠，维度作行标签；宽幅用矩阵。
- 禁止 ellipsis/line-clamp/overflow；单元格放不下就分行、拆页或删低价值维度。

## 逐项验收
- [ ] 维度口径统一，同一行各对象可比；对象列等宽对等。
- [ ] 结论是条件指向，无伪星级/伪分数/绝对化措辞。
- [ ] 无虚构参数/价格/评价；缺口显式标注。
- [ ] 多页页职责分明，对照页与条件页不重复整表。
- [ ] 长维度名、外文词真实试排，无溢出/裁切/无限缩字。
