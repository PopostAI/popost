# 步骤 · 有序操作与完成检查（step-guide）

## 适用
把一套有先后顺序的操作讲清「先做什么、再做什么、怎么算做完」，流程不绑定单一
商品推销。选用信号：怎么做、教程、分步、更换、安装、清洁、组装。不用于单商品
使用价值、横向比较、概念机制。

## 固定关系（不可破坏）
1. 编号即先后，不可调换跳步；上一步结果是下一步入口。
2. 每步三要素：动作 → 预期结果 → 与下一步衔接；不只有动作口号。
3. 前置材料/工具清单排在步骤前；安全/断电类提示在相关步骤旁可见，不藏末尾小字。
4. 必须出现完成态检查点（怎么算这步完成、整套做完的标志）。
5. 通用流程不伪装品牌官方教程；品牌专属操作以官方说明为准。

## 单页闭环
前置清单 + 3–5 有序步骤 + 完成检查，一套可独立照做。

## 多页分工
- 准备页：材料与前置条件。
- 操作页：按阶段分段，页尾明确「接着做什么」。
- 验收页：集中完成检查与常见失误。编号连续，不把一步拆两页凑数。

## 填写作业单
- [ ] 前置：需要哪些材料/工具/环境条件？
- [ ] 步骤：3–5 步（超 5 按阶段拆页），每步写动作、预期结果、衔接句。
- [ ] 安全：哪些步骤有断电/防烫/受力等注意，放在该步旁。
- [ ] 检查点：每步完成标志 + 整套完成标志。
- [ ] 常见失误：2–3 条，放验收页。

## 素材与红线
- 动作示意用内联 SVG 图标/简图，方向与文字一致并标「示意」。
- 真实工具/零件图需授权或确认；无图用泛型轮廓，不冒充具体型号。
- 效果类说法（净化率、口感、清洁力）无证据不写数值、不承诺。

## 容量与重排
- 单步超预算拆「动作+要点」两行，不缩字号；步骤 >5 按阶段拆页。
- 窄幅纵向链；宽幅可横向时间轴，序号方向与阅读顺序一致。
- 禁止 ellipsis/line-clamp/overflow；放不下拆步、拆页或删冗余装饰。

## 逐项验收
- [ ] 编号连续顺序正确，上步结果接入下步；每步动作/结果/衔接齐全。
- [ ] 前置清单在步骤前；安全提示位置可见；完成检查点明确。
- [ ] 无虚构效果数值、品牌教程伪装、价格销量评价。
- [ ] 多页阶段分工清楚，编号连续，页尾有衔接。
- [ ] 长步骤、外文词真实试排，无溢出/裁切/无限缩字。
