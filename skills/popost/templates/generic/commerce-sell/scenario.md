# 带货 · 情境动作价值路径（commerce-sell）

## 适用
把「用户情境/问题 → 商品身份 → 具体使用动作 → 价值回指动作或可核实属性 →
适用边界」组织成带货或非交易性商品说明。选用信号：怎么用、上手、使用场景、
搭配携带、价值主张。不用于横向多款比较、通用无商品流程、概念解释。

## 固定关系（不可破坏）
1. 顺序：先情境/问题，再商品身份与动作；每条价值必须回指一个动作或可核实属性，
   不允许悬空赞美（「很好用」必须能落到某个动作/属性）。
2. 一页一个主视觉焦点；身份图与动作示意分开，标签紧邻被指对象，不隔空引线。
3. 层级：主标题 → 视觉/动作 → 支撑说明 → 边界/下一步；CTA 可选，且不压过限制条件。
4. 同一商品跨页身份、名称、描述一致；未确认商品只用标注清楚的概念示意，不包装成
   真实在售商品。

## 单页闭环
情境标题 + 商品身份/明确示意 + 1–3 个动作或属性 + 适用边界，四者齐全。

## 多页分工
- 封面页：提出使用问题（hook 服务继续读，不标题党）。
- 动作页：给动作及理由，动作与价值相邻。
- 细节页（可选）：适配、维护、注意事项。
- 收尾页：归纳边界与下一步（CTA）。每页新增信息，不重复封面句；不为凑页拆一个
  动作成两页。

## 填写作业单
- [ ] 情境：谁在什么场景遇到什么小问题？（一句话）
- [ ] 商品身份：授权实拍/用户确认同款，或标注「示意」的概念图形。
- [ ] 动作清单：2–4 个具体动作，每个动作配一条可核实属性/价值回指。
- [ ] 边界：适用谁、不适用谁；未确认规格写「以规格为准」。
- [ ] CTA：查看规格 / 确认适配 / 保存使用步骤；价格只引用可核实资料。

## 素材与红线
- 价格、销量、评分、评价、折扣稀缺、效果/疗效承诺不虚构；无来源删除。
- AI/示意不得冒充真实商品外形、商标、认证；示意素材显著标「示意」。
- 不把相关性写成因果，不暗示不可能的效果或安全性；不承诺成交/转化。

## 容量与重排
- 短标题单行，中标题两行，长标题拆主标题+副说明；动作超 4 项拆页。
- 窄竖幅用上下关系，宽幅用左右 Grid；缺素材改动作/属性示意块，不留空图槽。
- 禁止 ellipsis/line-clamp/overflow 藏正文；溢出优先重排（分行/分栏/拆页）。

## 逐项验收
- [ ] 标题、情境与使用动作对应，价值点可回指动作/属性。
- [ ] 无虚构价格/销量/评价/效果；身份与示意用途可辨，示意有标注。
- [ ] 一页一焦点，标签紧邻对象，边界条件不被弱化。
- [ ] 多页信息增量明确，商品身份跨页一致，动作顺序连续。
- [ ] 无溢出/裁切/无限缩字；原尺寸查正文，手机缩略查标题层级。
