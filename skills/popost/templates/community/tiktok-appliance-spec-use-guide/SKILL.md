# 家电参数与使用场景图解

用场景图解释家电参数实际有什么用。

## 适用范围

采用“家电参数与使用场景图解”组织 家用电器 相关图文。设备要解释单位时间的产出、可处理范围和放置条件。可用示例包括制冰机、烘干设备、净化器、加湿器、台面设备。

参考案例，参考内容分型为“家电参数拆解卡”。观察到的风格：冰蓝白背景、深蓝粗无衬线标题，整机加材料剖面、操作面板和尺寸图。图像、文字和主体关系共同定义此模板；不能只保留商品题材就换成通用卡片。图组参考与观察依据见 [母图文依据](references/mother-post.md)，实际画面见 [原始图文首页](https://static.popost.ai/templates/tiktok-appliance-spec-use-guide/page-01-e235f2b6a780.webp)（完整图组列在 template.json 的 previews）。

## 输入与素材

整机、适用空间与尺寸、经核实的规格或实际测试。

整理用户商品图、已确认的名称/规格/价格/适配资料，以及出现人物时的角色参考。把广告叠字、实物包装字、社媒界面字分开记录；读取母图文字是理解文案结构，不是照抄他人品牌、个人经历、折扣或效果。

主体关系档案：整机P的门、面板、进出水口与资料尺寸一致；剖视图明确为结构示意，不把效果背景当真实冰量。逐页记录角色ID、商品或SKU ID、场景ID和状态；如果只是摄影组图，不强行虚构使用过程。

## 叙事与页型

文字推进方式：每页一个功能题，参数后接用途说明，用场景页收束适用范围。开场句式参考：“[设备]怎么用，先看这几张图”；方括号表示用用户事实替换，不是成品占位符。参数、清洁方式和容量来自说明书；多个场景可不同，但不能让设备外形换款

## 构图与文字

母图排版观察：冰蓝白背景、深蓝粗无衬线标题，整机加材料剖面、操作面板和尺寸图

字体与字号执行起点：Inter / Roboto Bold，中文 Noto Sans SC；深蓝页标题 50–72px，结构标注 30–42px，注释 26–36px。维持白蓝场景、实物与剖面示意的差别。 所有px以1080px画布宽度为基准，其他宽度等比换算。这些是根据可见风格给出的制作建议，不是识别出的原帖字体文件或精确原始字号。以参考图中的文字位置、粗细、行数、占幅和手机阅读效果校准；不默认把字统一放最上方。

产品尺寸与使用环境分栏，单位和条件紧贴数字。 对照每一张图重排：关键主体、五官、产品结构和前后差异必须能看见。包装字和衣服印花跟随真实商品保留；新写的Hook、正文、标签在画布中使用可编辑文本。独立广告叠字出现在哪几页，以前节逐画面计划为准。

## 整组视觉

统一参数版式，清楚区分实测、额定和示意。

连续性必须落实到本模板的主体关系：整机P的门、面板、进出水口与资料尺寸一致；剖视图明确为结构示意，不把效果背景当真实冰量。开始制作前为重复主体选一张主参考；后续改变镜头、动作或状态时，沿用能识别它的脸部/发型/服装、包装/结构/纹理、背景锚点。明确的多色选款、双产品比较和多角色阵容允许出现不同主体，但必须分别标识，不能误当生成漂移。

跨页反差只改变已说明的变量：前后状态、对比SKU或使用步骤。保持其他比较条件可比，不能通过换人、换产品、换光线或缩放比例制造不存在的改善。字体角色、标签样式和强调色全组统一，不要求每页构图完全相同。

没有产出条件时仅列经确认的规格和位置。纯安装说明走 G01。

## 交付与验收

每个数值有单位与条件，放置位置符合产品信息。

1. 把开头承诺与结尾兑现对应起来，检查每页文字是否能由当前图片或资料支持。
2. 并排检查母图与新图的文字位置、字重、字号层级、行数和图像占比；没有把安静摄影组图改成密集文案海报。
3. 按角色、商品/SKU、场景与状态档案逐页核对；重点检查前后比较是否换了人、换了产品或混用了变体。
4. 包装文字、印花、部件数、配件和数字单位与用户资料一致；无虚假价格、促销、评价或前后效果。
5. 逐页在原尺寸与手机预览宽度检查可读性，整组缩略图检查连贯；字体真实加载，主体不被字遮住。
6. 新广告文案保持可编辑，图片与文案一起提交给宿主画布。发布文案可另写，但不能用发布正文代替图上的Hook与跨页文案。
