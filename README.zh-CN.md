## 贴链接。做整篇。继续改。

1. **贴帖子链接。** 支持可访问的 TikTok、抖音、X、小红书、Instagram 帖子。也可以给截图、直接说主题，或选 Skill 模板。
2. **给新主题和素材。** Agent 参考开场、页序、文案层级、图片和排版，做成完整单图或多页图文。
3. **在画布里接着改。** 改真实文字、换图片、调整图层和页面，最后导出 PNG。普通编辑不需要再次付费生成。

Agent 侧边栏和 [popost.ai](https://popost.ai) 使用同一套画布。连接账户后，Skill 可以把工程同步到你的账号；未连接时可以先在本地创作，之后再点**保存到云端**。支持的帖子链接也可以保存到账号的**我的灵感**。

## 开始创作

从 npm 安装 Skill 和命令行：

<!-- install:start -->
~~~bash
npm install -g popost
popost install
~~~

需要 Node.js 20.19+；macOS、Windows、Linux 通用。<code>popost install</code> 会识别 Codex 和 Claude Code；其他 Agent 可用 <code>popost install --dir &lt;skills 目录&gt;</code>。想试开发版，就在本仓库的 <code>develop</code> 分支构建（<code>npm ci</code>、<code>npm run build:skill</code>、<code>npm install -g ./skills/popost</code>），并保留这个源码目录：全局 CLI 会指向它。
<!-- install:end -->

然后对 Agent 说：

~~~text
/popost 参考这篇两页的 TikTok 图文结构：
https://www.tiktok.com/@veyla_gift/photo/7699494320675507469
给我的手链做一篇新的送礼故事，保留“情绪钩子 → 商品揭晓”的节奏。
文案重新写，商品只用 ./photos/bracelet.jpg 这张照片。
做完打开完整画布，我要继续改字和版式。
~~~

没有链接？直接让 Agent 做一篇五页的小红书分享，或者选一个 [Skill 模板](./skills/popost/templates/community/)。完整流程见 [Skill 说明](./skills/popost/SKILL.md)。

## 哪些步骤用算力？

| 操作 | Popost 算力 |
| --- | --- |
| 解析帖子链接，或把帖子保存到「我的灵感」 | 使用；提交前先看实时报价 |
| 用 Popost 模型生成图片 | 使用；运行前先报价 |
| 写改文案、排版、渲染、画布编辑、导出 PNG | 不使用 |

首次使用站内服务时，运行 <code>popost auth login</code>，在浏览器输入设备码并允许连接。你可以在账户设置里随时断开。<code>popost link quote</code> 和 <code>popost inspiration quote</code> 可查看当下的链接费用。也可以使用自己的图片模型或 Agent 自带的生图工具；详见 [providers](./skills/popost/references/providers.md)。
